# 필요한 음원 목록

지금 없는 음원이다. **없어도 화면은 그대로 동작한다** — `playSample` 이 실패하면
`app.js` 의 합성음이 대신 울린다. 파일을 `public/sfx/` 에 넣는 순간 자동으로 그쪽이
쓰이고, 코드를 고칠 필요는 없다(`SFX_EXT` · `SFX_SETS` 에 이름이 이미 올라가 있다).

넣은 뒤에 할 일은 하나다: **`SFX_NORM` 에 음량 보정값을 재서 넣는다.** 이 서비스의
효과음은 실효 RMS 를 −32dB 근처로 맞춰 두었는데, 원본 음량은 파일마다 10dB 이상
차이가 난다. 보정 없이 넣으면 새 소리 하나가 다른 소리를 전부 압도한다.

## B · `box-open.mp3` / `box-shake.mp3` 사양

두 소리는 미스터리 바운티 개봉 연출에 쓴다. 연출 길이가 정해져 있으므로
**음원 길이를 그 구간에 맞춰야 한다** — 길면 다음 박자를 덮고, 짧으면 무음이 생긴다.
연출 구간은 `src/web/games/holdem-client/seats.ts` 의 `MYS_*` 상수다.

### `box-shake.mp3`
- **길이 1.4 ~ 1.5초** (연출 구간 `MYS_SHAKE_MS = 1500`)
- 상자가 좌우로 덜커덩거리는 소리. 나무/금속 상자가 안에서 무언가에 밀려 흔들리는 느낌
- **불규칙한 간격**으로 5~7번. 고른 간격이면 기계 소리로 들린다
- 뒤로 갈수록 조금 커지면 좋다 (긴장이 올라가는 방향)
- 저역 중심(200~500Hz). 고역이 세면 열림 소리와 다투게 된다
- 페이드아웃 없이 끝나야 한다 — 곧바로 열림 소리가 이어진다

### `box-open.mp3`
- **길이 1.0 ~ 1.3초** (연출 구간 `MYS_OPEN_MS = 520` + 금액 체류 `MYS_HOLD_MS = 1700`)
- 뚜껑이 열리며 빛이 뿜어져 나오는 순간. 짧은 "쉭" + 상승 화음 + 끝에 남는 반짝임
- 잭팟 계열이지만 **1초 안에 끝나는 짧은 것**이어야 한다. 4초짜리 음악을 넣으면
  다음 판이 시작된 뒤에도 울린다
- 우승 팡파르(`tournament-win.mp3`)와 구분돼야 한다 — 그건 대회 전체가 끝났을 때다

## 포맷 (기존 음원과 동일하게)

- MP3, 44.1kHz, 모노 (스테레오여도 되지만 파일이 두 배가 된다)
- 앞뒤 무음을 잘라 둘 필요는 없다 — `app.js` 의 `trimSilence` 가 최대치의 2% 를
  기준으로 잘라낸다
- 파일 하나가 100KB 를 넘지 않는 것이 좋다. 이 소리들은 홀덤 화면에 들어갈 때
  미리 받아 두므로(`__SFX_NEED__`) 첫 로딩에 그대로 얹힌다

## 음원을 바꿀 때 함께 봐야 하는 것

`gunshot.mp3` 는 **세 발의 발사 시각이 코드에 박혀 있다** —
`app.js` 의 `gunfireShots: [30, 305, 1335]` (ms). 화면이 이 값을 읽어 총알이 박히는
순간을 맞추므로, 음원을 교체하면 이 배열도 다시 재서 넣어야 한다. 안 그러면
소리와 총자국이 어긋난다. 재는 방법은 그 상수 옆 주석에 적어 뒀다.
